# AI Video Studio v0.2

## Что это
Локально-ориентированный веб-интерфейс для планирования производства длинных YouTube-видео на Android. Версия 0.2 — планировщик и менеджер проектов, а не готовый генератор видео.

## Возможности
- Создание проектов и производственного плана из идеи.
- Просмотр проектов и удаление с подтверждением.
- Очередь этапов и счётчики задач.
- Style Bible: правила рисовки, палитра и персонажи.
- Локальное сохранение в браузере.
- Экспорт и импорт резервной копии JSON.
- Мобильное боковое меню с крестиком, затемнением, закрытием по фону и Escape.
- PWA manifest и базовый Service Worker для кэширования файлов.

## Установка на GitHub Pages
1. Распакуйте архив.
2. Замените файлы в корне репозитория: `index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `README_RU.txt`.
3. Сделайте Commit changes в ветку `main`.
4. Откройте GitHub Pages и обновите сайт. Если старая версия отображается, очистите данные сайта/кэш Chrome или откройте сайт в приватной вкладке.

## Важно
- Внешние ИИ/API не подключены.
- Нельзя безопасно хранить секретные API-ключи в JavaScript на GitHub Pages.
- Автоматическое выполнение задач, ожидание квот и сборка MP4 пока не реализованы; очередь сейчас хранит план и статусы.
- Данные проектов хранятся локально в браузере и не синхронизируются между устройствами. Делайте экспорт JSON.
- Service Worker работает только на HTTPS или localhost.

## Совместимость
Современный Chrome/Chromium на Android. При проблемах с обновлением PWA очистите кэш сайта и перезапустите страницу.
